# Finding Maximum Value in a List

## Problem Statement
You are tasked with implementing a Python function find_max that finds the maximum value in a list of integers or floating-point numbers. The function should be type-safe and restrict the input list to contain only integers or floating-point numbers.

## Requirements
The find_max function should have the following signature:

1. The function should accept the following argument:
    - arr (type List[T]): A list of elements of type T, where T is a type variable bounded by int and float.
2. The function should return the maximum value in the list. If the list is empty, it should raise a ValueError with an appropriate error message.

## Instructions
- Implement the find_max function according to the specified requirements.
- Ensure that the function handles empty lists by raising a ValueError.
